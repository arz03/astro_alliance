3. Derived Feature Engineering Equations

#### 3.1 Escape Velocity Model Conversion (vₑ)
Calculates the exact escape velocity of any row profile using standard SI metric expansions:

v_e = sqrt((2 * G * M) / R)

Where:
- G = 6.6743 × 10⁻¹¹  
- M = pl_bmasse × 5.9722 × 10²⁴  
- R = pl_rade × 6.371 × 10⁶

---

#### 3.2 Dimensionless Transit Signal Depth Calibration (pl_ratior)
Establishes geometric size validation bounds between planet disks and stellar radii:

pl_ratior = (pl_rade × 6.3710 × 10⁶) / (st_rad × 6.9570 × 10⁸)
